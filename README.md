# FireShield

Working repository for the Amazon **Build, Ship, Shape** developer hackathon, with **Fire TV** as the intended primary track.

## Current status

The repository currently contains the research and validation foundation. The product idea, target user, prototype selection, and application stack are **not finalized**. There is no runnable Fire TV application yet.

The name FireShield is the working repository name; it does not establish the product's purpose.

## Start here

- [Project brief](docs/research/project-brief.md): capture the researched idea and unresolved decisions.
- [Repository assessment](docs/research/repository-assessment.md): findings about the two proposed research tools.
- [Evidence register](docs/research/evidence.csv): record sources, claims, and contradictory evidence.
- [Validation plan](docs/validation/plan.md): test technical assumptions and business demand.
- [Hackathon checklist](docs/hackathon/submission.md): prepare platform evidence and submission materials.
- [Prototype workspace](prototypes/README.md): define and compare small experiments.

## Immediate next step

Import the user's previous research document, retain its source attribution, distinguish findings from hypotheses, and map the proposed prototypes against evidence and Fire TV constraints. Choose the first experiment after that review.

## Development approach

Validate a narrow user problem, demonstrate one useful end-to-end TV flow, and then expand only where evidence supports it. Record decisions and experiment outcomes in this repository.

Amazon's [multi-TV sample](https://github.com/AmazonAppDev/react-native-multi-tv-app-sample) is a candidate application foundation. It has not been imported, built, or tested here.

## Setup and operation

No dependency installation is required to review this documentation. Application setup and run commands will be added after the stack is selected.

No external services, API keys, deployments, research jobs, or scheduled background work are configured.

## Sources and reuse

No source code from the proposed third-party research repositories has been copied. The assessment records concerns about incomplete implementation and unclear reuse terms. The license for this project's original code remains to be selected before an open-source submission.
