# Prototype workspace

No prototypes have been implemented yet. The user's previous research document will establish the candidate concepts.

Give each candidate a short identifier and its own directory once there is a concrete experiment to implement.

## Before implementation

Record:

- Target user and specific task.
- Hypothesis being tested and comparison baseline.
- Why the task belongs on Fire TV.
- Target platform and required supported capability.
- Smallest complete flow that can test the hypothesis.
- Inputs, outputs, dependencies, and data/content permissions.
- Success/failure measures chosen before testing.
- Expected operating costs and important unknowns.

## After implementation

Add setup/run commands, environment information, actual observations, known limitations, and a keep/revise/abandon decision. Link the validation experiment and evidence register.

Begin with the experiment that resolves the most consequential uncertainty. Do not expand all possible prototypes before reviewing the concept and evidence.
